 FastAPI Frontend-Backend Demo
A simple demo project built to understand how FastAPI 
connects with a frontend using REST APIs.

 Project Structure
fastapi-demo/
├── frontend/
│   └── index.html        # Frontend with fetch API calls
├── backend/
│   ├── main.py           # FastAPI app with API endpoints
│   ├── requirements.txt  # Python dependencies
│   └── __pycache__/      # Auto-generated by Python

Tech Stack
- Frontend: HTML, JavaScript (Fetch API)
- Backend:FastAPI (Python)
- Communication: REST API (JSON)

How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Start the backend:
   uvicorn main:app --reload

3. Open frontend/index.html in your browser

 What I Learned
- How FastAPI handles GET and POST requests
- Connecting a plain HTML frontend to a Python backend
- REST API structure and JSON data flow
- Using requirements.txt for dependency management

 Note
This is a learning project built while exploring 
FastAPI and full-stack communication.
